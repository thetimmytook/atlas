# Платформы, доступность и нагрузка

[Основная навигация](../DESIGN_MAIN.md)

## Принято

- Современные Chrome, Firefox, Safari, Edge; Safari на iOS и Chrome на Android.
  Конкретные минимальные версии ещё не выбраны.
- Ввод мышью и touch; базовая навигация камерой с клавиатуры.
- Интерактивные объекты должны допускать фокус и активацию с клавиатуры;
  детали доступности проверяются прототипом.
- По отдельному указанию пользователя обработчики клавиатуры остаются под вопросом:
  конкретные клавиши, API регистрации/перехвата, фокус и распределение ответственности
  между Atlas и приложением ещё не утверждены.

## Измерение референса tarkov.dev

Проверено 2026-09-25. Источник: https://json.tarkov.dev/regular/maps
Режим regular. Путь API установлен из исходного кода:
https://github.com/the-hideout/tarkov-dev/blob/main/src/features/maps/do-fetch-maps.mjs
https://github.com/the-hideout/tarkov-dev/blob/main/src/modules/api-request.mjs

Подсчитаны длины массивов: spawns, extracts, transits, locks, hazards, lootContainers, lootLoose, switches, stationaryWeapons, btrStops.
Это записи исходных категорий, не уникальные видимые маркеры и не DOM-узлы.
Не включены квестовые цели, подписи из конфигурации, SVG-подложка, пользовательские
маршруты и вложенная геометрия. Отсечение и фильтры могут уменьшать видимое количество;
одна запись может создавать несколько визуальных элементов.

Согласованный ориентир для прототипа: базовый сценарий порядка 3000

Частота обновлений, длины маршрутов, целевые устройства, FPS/время загрузки и бюджет
памяти ещё не определены; число объектов само по себе не описывает всю нагрузку.

## Выявленный вопрос модели clipping

Источник: https://github.com/the-hideout/tarkov-dev/blob/main/src/data/maps.json
Streets использует глобальные диапазоны высоты для уровней. Reserve задаёт для
одного отображаемого этажа несколько extents с разными диапазонами высоты и
локальными bounds зданий. Единый прямоугольный clip не воспроизводит такой
совмещённый этаж напрямую. Decision point: несколько слоёв под общим управлением
или объединение нескольких областей clipping. Текущую модель автоматически
не расширяем; произвольные формы clipping по-прежнему отложены.
