# Ресурсы и сериализация

[Основная навигация](../DESIGN_MAIN.md)

## Принято: реестр ресурсов карты

- Ресурсы описываются в отдельном реестре: подложки, иконки, шрифты,
  в перспективе 3D-модели.
- В JSON описание ресурса хранится один раз под ID. Объекты и материалы
  ссылаются на этот ID. Atlas загружает и переиспользует ресурс.
- Приложение может подключить собственный загрузчик, например для авторизации
  или локальных файлов. Runtime-функции загрузчика не входят в сериализуемый JSON.
- Ошибки загрузки обрабатываются строго, согласно правилам загрузки карты.
- Точные схемы ресурсов, API загрузчика, область кеша, освобождение ресурсов,
  стратегия загрузки и состав экспорта пока не определены.

## Принято: состав документа карты

- schemaVersion.
- Пространство и границы карты.
- objects и layers.
- Материалы и правила их назначения.
- Реестр ресурсов.
- homeView и ограничения камеры.

Регистрации обработчиков, загрузчики и другое исполняемое поведение находятся
в конфигурации приложения, вне JSON. Карта содержит данные отображения,
приложение предоставляет код расширений. Точные названия остальных полей
и полная схема ещё не определены.

## Открыто: экспорт runtime

Состав документа согласован, но ещё нужно определить, какие текущие изменения
runtime попадают в экспорт, как представлены defaults и ссылки на встроенные
материалы. Хранение пользовательской сессии остаётся ответственностью приложения.
